================================================================================
PHASE 12C — SUPABASE AUTH (OPTIONAL LOGIN)
================================================================================

Goal:
  Let you create an email account so tips you log can belong to you.
  Still optional — leave env vars empty and the app works as before.


--------------------------------------------------------------------------------
PLAIN ENGLISH
--------------------------------------------------------------------------------

  App access key (12A) = one password for the whole server (house key).
  Account login (12C)   = your personal email login (your room).

  You can use neither, either, or both.


--------------------------------------------------------------------------------
WHAT SHIPPED
--------------------------------------------------------------------------------

  Backend
    - tips.owner_id column
    - Verify Supabase JWT (Authorization: Bearer)
    - X-API-Key only for APP_API_KEY (Bearer no longer used for that)
    - GET /auth/status
    - Logged-in tip list/create scoped to that user
    - AUTH_REQUIRED_FOR_TIPS=false by default

  Expo Me → Account
    - Sign up / Sign in / Sign out
    - Password minimum 8 characters (app-enforced)
    - Session stored securely; API calls send the login token

  Web dashboard Me → Account (same Supabase login)
    - GET /auth/config serves public URL + anon key from server .env
    - Sign in / sign up / sign out; Bearer token on API calls
    - Requires SUPABASE_URL + SUPABASE_ANON_KEY on Render / local .env

  Also set in Supabase (Auth → Providers → Email / password settings)
    minimum password length ≥ 8 so the server matches the app.


--------------------------------------------------------------------------------
HOW TO TURN ON
--------------------------------------------------------------------------------

  1) Supabase dashboard → Authentication → enable Email provider
  2) Project Settings → API:
       - Project URL
       - anon public key
       - JWT Secret
  3) Server .env / Render:
       SUPABASE_JWT_SECRET=<jwt secret>
       SUPABASE_URL=<url>          (optional, for docs)
       SUPABASE_ANON_KEY=<anon>    (optional, for docs)
  4) mobile/.env  (IMPORTANT: Expo does NOT read the repo-root .env)
       EXPO_PUBLIC_SUPABASE_URL=<url>
       EXPO_PUBLIC_SUPABASE_ANON_KEY=<anon>
  5) Restart Expo with cache clear:
       cd mobile && npx expo start --clear
  6) Me → Account → Sign up / Sign in → Log tips

  Later, to force login for tip writes:
       AUTH_REQUIRED_FOR_TIPS=true
