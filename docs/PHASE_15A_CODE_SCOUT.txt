================================================================================
PHASE 15A — CODE SCOUT FEED + APP LOCK
================================================================================

Goal:
  Brand moment: auto-list booking codes for the selected bookmaker (SportyBet /
  Bet9ja), with filters + copy. Also optional device biometrics App Lock.


--------------------------------------------------------------------------------
WHAT SHIPPED
--------------------------------------------------------------------------------

  15A-1  Scouted codes backend
    - Table scouted_codes (book + code unique)
    - GET /scout/codes — today→future only; filters odds, folds, risk_band, sort
      (past-dated codes purged on list/refresh; lookback `days` ignored)
    - POST /scout/refresh — admin web + Twitter ingest
    - POST /scout/codes — admin manual add
    - POST /scout/ingest-text — admin Twitter/tipster paste parse
    - Auto ingest when feed empty (refresh_if_empty)
    - Ingest skips codes whose page/tweet date is before today (Africa/Lagos)

  15A-2  Web + Twitter sources (free, multi-book)
    - SureCodes24 + BettingInAfrica (SportyBet pages)
    - Curated X handles: SCOUT_TWITTER_HANDLES=sportybet:Handle,bet9ja:Handle,nairabet:Handle
    - Free RSS mirrors (no paid X API); SCOUT_TWITTER_SKIP_LOTTERY=true
    - Auto refresh on admin Load matches (/odds/sync) + morning ops
    - Scout tab pull reloads DB; admin Refresh forces ingest
    - UI “Good only” = safer + stretch

  15A-3  Mobile Code Scout (main tab)
    - Tab bar: Home · Scout · Surebets · Tools · Account
    - Tips → Account → Tip history
    - Bookmaker switch, Today+ filters (no lookback period), Copy code, Open book

  15A-4  App Lock (biometrics)
    - expo-local-authentication
    - Account → Settings → App Lock


--------------------------------------------------------------------------------
HOW TO SMOKE-TEST
--------------------------------------------------------------------------------

  Code Scout
  1. Sign in → Scout tab (not Tools).
  2. Prefer SportyBet / Bet9ja; codes appear after Load matches or admin Refresh.
  3. Filter Good only; Copy code; paste into the book Load Code field.
  4. Switch book — feed scopes to that bookmaker.

  App Lock
  1. On a device build: Account → Settings → App Lock on.
  2. Background the app → reopen → fingerprint / Face ID / PIN unlock.
  3. Web: toggle message says lock is native-only.
