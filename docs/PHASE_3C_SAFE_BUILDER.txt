================================================================================
PHASE 3C — BANKROLL UNITS + SAFE BUILDER
================================================================================

Goal:
  Size stakes from your Naira bankroll, then suggest "safer" singles / DC /
  flex-multi legs using YOUR SportyBet-style rules.

  This is NOT a surebet. Picks can still lose.


--------------------------------------------------------------------------------
YOUR RULES (encoded in app/services/safe_builder.py)
--------------------------------------------------------------------------------

  Priority order (first match wins):

  1) Underdog > 10 (esp. 10–13+)
       → profile: accumulator_flex
       → favourite only inside a multi; prefer Flex (e.g. 9/10)

  2) Underdog > 7
       → profile: safe_double_chance
       → always double chance covering the favourite:
            home favourite → 1X (Home or Draw)
            away favourite → X2 (Away or Draw)

  (Underdog 5–7 / medium_underdog is OFF for now — too easy to over-trust.)
  (Straight favourite when dog >7 is OFF — DC only.)


--------------------------------------------------------------------------------
BANKROLL UNITS
--------------------------------------------------------------------------------

  Example: bankroll ₦50,000, unit = 1% → ₦500 per unit.

  Default stake multipliers:
    safe_double_chance → 1.0 unit
    accumulator_flex   → 0.5 unit (whole slip)


--------------------------------------------------------------------------------
HOW TO TEST
--------------------------------------------------------------------------------

Offline (no keys):

  python scripts/demo_safe_builder.py

API / dashboard (server running):

  http://127.0.0.1:8000/          → click "Scan Safe Builder"
  POST /bankroll/size
  GET  /safe-builder/scan?bookmaker=sportybet&bankroll_ngn=50000
  POST /safe-builder/evaluate     → paste home/draw/away from odds-api.io

Tip: sync NG odds first (Phase 3B), then scan Safe Builder on SportyBet.
