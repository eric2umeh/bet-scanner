================================================================================
PHASE 5B — AI EXPLAIN + DECISION BRIEF
================================================================================

Goal:
  Engines (Safe Builder / value / surebets) still decide WHAT to tip.
  AI (optional) explains WHY in plain English — like a coach, not a crystal ball.

  Without AI_API_KEY → template explanations (always works).
  With key → OpenAI-compatible chat (OpenAI, Groq, etc.).


--------------------------------------------------------------------------------
IMPORTANT
--------------------------------------------------------------------------------

  AI does NOT replace Safe Builder or invent sure wins.
  Use brief after Sync NG odds so scans have fresh prices.


--------------------------------------------------------------------------------
DASHBOARD (2 minutes)
--------------------------------------------------------------------------------

  1) Refresh http://127.0.0.1:8000/
  2) Set Bankroll ₦ + Unit % + Pick style
  3) Sync NG odds (if stale)
  4) Click “AI decision brief”
  5) Optional: tick Notify Telegram → brief text is sent


--------------------------------------------------------------------------------
API
--------------------------------------------------------------------------------

  POST /ai/explain
       body: { "engine": "safe_builder", "pick": { ...scan pick... } }

  POST /ai/brief
       body example:
       {
         "bankroll_ngn": "50000",
         "unit_pct": "1",
         "pick_market": "double_chance",
         "prefer_llm": true,
         "notify_telegram": false,
         "max_explains": 3
       }


--------------------------------------------------------------------------------
CONFIG (.env optional)
--------------------------------------------------------------------------------

  AI_ENABLED=true
  AI_API_KEY=sk-...
  AI_BASE_URL=https://api.openai.com/v1
  AI_MODEL=gpt-4o-mini

  # Groq example:
  # AI_BASE_URL=https://api.groq.com/openai/v1
  # AI_MODEL=llama-3.1-8b-instant
